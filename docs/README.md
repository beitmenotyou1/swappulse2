# SwapPulse Documentation

SwapPulse is a decentralised social network and toolkit for Pokémon TCG collectors. Track your collection, trade with greater confidence, join the community and keep control of your identity and data.

| Choose your path                            | What you will find                                         |
| ------------------------------------------- | ---------------------------------------------------------- |
| [Start Here](start-here/)                   | Create an account and learn the essentials.                |
| [Help Centre](help/)                        | Get practical guidance for every product feature.          |
| [Developers](developers/)                   | Build, integrate with or contribute to SwapPulse.          |
| [Network & Web3](network-and-web3/)         | Understand identity, staking and the live V2 architecture. |
| [Project Maintenance](project-maintenance/) | Release, govern or fork the project safely.                |
| [Changelog](changelog/)                     | See every recorded release, newest first.                  |

{% hint style="success" %}
SwapPulse is free and open source. The project is designed around portability, self-custody and community control.
{% endhint %}
