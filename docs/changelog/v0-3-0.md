# SwapPulse v0.3.0: Navigation and standalone Chain Explorer

This is a backfilled historical release from the preserved navigation/explorer checkpoint.

## New features

* Standalone `/chain/*` Chain Explorer application surface.
* Latest-block and latest-transaction views.
* Dedicated block, transaction and smart-account address pages.
* SwapPulse-indexed smart-account activity.
* Direct Wallet → Explorer address and transaction links.
* GitHub links in visible footer/navigation surfaces.

## Updated components

* Explore remains a primary navigation destination.
* Chain Explorer is intentionally moved to the footer rather than occupying the social navigation.
* Desktop and mobile More menus are scrollable and less cluttered.
* Explorer includes language switching, theme control, skip navigation and the site's accessibility preferences.

## Removed

* Duplicate Wallet entry from More.
* Duplicate Chain Explorer entry from More.
* Redundant Explore footer link.

## Design rationale

The social application and blockchain explorer serve different jobs. The explorer now looks and behaves more like a dedicated blockchain tool, while the main site navigation stays focused on collector/community activity.

## Data-model note

The address activity shown by the explorer is explicitly described as SwapPulse-indexed activity. It is not presented as complete archive indexing until a true archive/indexer layer exists.
