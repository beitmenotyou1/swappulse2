# SwapPulse v0.1.0: Frozen V2 live baseline

This is a backfilled historical release created from the preserved final V2 deployment checkpoint.

## What was added

* Cairo/Starknet V2 identity registry and SwapPulse smart-account architecture.
* SWPX native token and community staking contracts.
* Supporting CardNft, ProofOfUsership and BridgeAdapter contracts.
* Hardened transaction relay and read-only public RPC gateway.
* Base44 ↔ Starknet reconciliation and V2 assurance metadata handling.

## What changed

* Base44 became the application/orchestration layer while Cairo/Starknet became the decentralised trust and verification layer.
* Identity records use opaque IDs, commitments, verification metadata, timestamps, expiry and revocation state rather than private personal information.
* V2 verification became permanently required on the live testnet.

## Security and verification

* Cairo/Foundry: 64 tests collected, 63 passed, 0 failed, 1 intentionally ignored and separately verified.
* Relay policy smoke regression passed.
* Unauthorised writes, replay protection, duplicate registration, expiry, revocation, verifier permissions, staking controls and malicious callers were covered.
* Public and local `/readyz` checks confirmed the V2 contract pins and ecosystem readiness.

## Why this release matters

This checkpoint is the stable post-cutover foundation for every later product-layer release. No later release should weaken its privacy, key-management, replay-protection or fail-closed verification rules without an explicitly reviewed protocol migration.
