# SwapPulse v0.11.0 development preview: Helper, Scanner and clearer navigation

{% hint style="warning" %}
This page describes work implemented for the planned v0.11.0 experience. It is not an authoritative release declaration. The repository package and release manifest remain at v0.10.0 until the normal release process records v0.11.0.
{% endhint %}

This preview focuses on simpler names, safer card-photo workflows, multilingual assistance and a more usable site menu.

## Clearer names

The visible product names are now:

* **Wallet**, previously shown as “SwapPulse Wallet”;
* **Helper**, previously shown as “Collector Copilot”;
* **Scanner**, previously shown as “Scan Cards” or “Card Scanner”.

Existing technical filenames, stored agent identifiers and the old Helper URL may remain for compatibility. The old Helper URL redirects to the current /helper route.

## Helper

[Helper](../ai-assistants/collector-copilot.md) is the signed-in, read-only assistant for collection, card, trade, Pokémon TCG, SwapPulse project and documented chain questions.

It:

* defaults to the language saved in the user's account;
* offers a language menu for English (UK), Spanish, French, German, Italian, Portuguese (Brazil), Japanese, Simplified Chinese and Korean;
* uses authorised account records, catalogue data, stored market context and administrator-approved project knowledge;
* keeps fetched project text and feedback-derived suggestions quarantined until review;
* cannot change a collection, publish content, send a message, operate Wallet or submit a blockchain transaction.

The language marker controls response language only. It never grants authority or changes access controls.

## Scanner

[Scanner](../collection-and-catalogue/card-scanner.md) now supports two deliberate workflows.

### Collection intake

A signed-in collector can upload or photograph 1 to 10 private card images. Scanner proposes TCGDex catalogue matches, and the collector reviews identity, condition, finish and quantity before explicitly confirming any collection entry.

### Post, quote and comment attachment

A composer can accept one uploaded or photographed card. Scanner presents up to three catalogue candidates and allows manual catalogue correction. Selecting **Use in post** attaches the reviewed catalogue card to the draft.

This action does not:

* publish the post, quote or comment;
* add a card to Collection;
* create a listing or trade;
* prove possession or authenticity;
* submit a Wallet or blockchain action.

Manual card search and the Collection picker remain available.

## Menu and scrolling

The mobile **More** menu is organised into Tools, Community, Activities, Account and Administration. Legal, documentation, status, explorer, donation and source links sit in the compact information area rather than competing with feature shortcuts.

The menu uses its own viewport-bounded scroll region, safe-area padding, body-scroll locking and Escape-to-close behaviour. This keeps the final menu items and compact footer reachable even on short screens and pages whose main content does not scroll.

## Footer consistency

The large Documentation and Status card footer has been removed from normal page layouts. The remaining footer presentation is the compact link treatment used for Documentation, Status, Terms, Privacy, Chain Explorer, Donate and GitHub, followed by the project and trademark notice.

## Safety and data boundaries

* Card photographs remain private and use short-lived access links for analysis.
* Image text is treated as untrusted data, not an instruction.
* Scanner suggestions require collector review.
* Scanner corrections remain quarantined until administrator approval.
* Helper is advisory and read-only.
* Neither feature automatically trains itself from unreviewed content.
* Neither feature silently creates a post, collection entry, attestation, trade or blockchain record.
