# SwapPulse v0.4.0: Wallet overview UX refresh

This is a backfilled historical release from the preserved Wallet overview checkpoint.

## New features

* Asset-first SWPX Wallet overview.
* Prominent network/account presentation.
* Familiar Receive, Get SWPX, Stake and Send navigation actions.
* Direct smart-account Chain Explorer access.
* Wallet-specific localisation bundle covering all supported interface languages.

## Updated components

* Wallet now opens with a familiar account/balance experience before presenting deeper Identity, recovery, card, staking and bridge tools.
* Security and V2 identity information remains available rather than being removed for the sake of visual simplicity.

## Security

* This is a presentation/navigation release. Signing authority, relay policy, chain eligibility checks, verification expiry/revocation behaviour and server-side transaction validation were not moved into browser code.

## Why

Users coming from wallets such as MetaMask, Trust Wallet, Phantom, Ledger, Trezor or Exodus should recognise the basic interaction model while still seeing SwapPulse's distinctive Identity, Pokémon-card and community-staking capabilities.
