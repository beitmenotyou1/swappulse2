# Official links & support

Use this page to confirm that you are visiting an official SwapPulse service or contacting the project through a recognised support channel.

{% hint style="warning" %}
SwapPulse support will never ask for your password, seed phrase, private key or authentication code. Do not send card-payment details, identity documents or other sensitive information through public messages.
{% endhint %}

When reporting a problem, include the page you were using, what you expected, what happened and any non-sensitive error text. Do not include credentials, private keys, recovery material or private card images.

For service availability, see [System Status](../platform/status.md). For common fixes, see [Troubleshooting](../support/troubleshooting.md).
