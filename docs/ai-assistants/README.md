# AI Assistants

Use [Helper](collector-copilot.md) as the multilingual, read-only front door for collection, card, trade, project and chain questions. It defaults to your account language, and you can choose another supported language from its menu.

Focused assistants remain available for deeper collection, trade, market, goal and community workflows.

AI output is advisory. Review important details before acting, and never share a password, seed phrase, private key or authentication code with an assistant.

Choose a guide from this section's navigation.
