## Licence at a glance

MPL-2.0 is an open-source, file-level copyleft licence. It allows you to:

* use SwapPulse for personal, community or commercial purposes;
* inspect, copy and modify covered source files;
* distribute original or modified versions;
* combine MPL-covered files with separate open-source or proprietary files in a larger work.

The file-level copyleft requirement means that when you distribute a modified MPL-covered file, that covered file and its source must remain available under MPL-2.0. Separate files that contain no MPL-covered code can use different terms.

## Hosting and private changes

MPL-2.0 is not an AGPL-style network copyleft licence. Using or modifying SwapPulse privately, including within an organisation, does not by itself create an external source-distribution requirement.

Running modified server-side code as a hosted service is not automatically distribution under MPL-2.0. Code delivered to a user's device, such as browser JavaScript, can count as distributed code. If you distribute covered code or executables, follow the obligations above.
