# How are new FAQ questions added?

Each new question receives its own page in the [Frequently Asked Questions](./) category.

When new features, documentation or behaviour are added, maintainers review the change from a user's point of view. If it raises a useful question that is not already answered, they create a dedicated FAQ page rather than adding another entry to the consolidated archive.

A new FAQ page should:

* use the full question as its page title;
* give a concise, direct answer first;
* explain only the context needed to understand the answer;
* link to the detailed guide instead of duplicating it;
* use plain language and explain unavoidable technical terms;
* state limitations, security or privacy implications where relevant;
* be added beneath the FAQ category in `docs/SUMMARY.md`;
* be reviewed whenever the related feature changes.

The existing [All current FAQ answers](../support/faq.md) page remains available as the consolidated archive. New questions should not be appended to it.

This approach gives every answer a stable page that is easier to search, share and keep current.
