## How this category is organised

The existing consolidated FAQ is preserved so no answer or incoming link is lost. From now on, each new question receives its own page in this category. The page title is the question, the direct answer comes first, and links lead to the fuller guide where useful.

Whenever SwapPulse gains new content or behaviour, maintainers review it for likely questions. Relevant unanswered questions are added here rather than buried inside a long guide.

## Still need help?

If you cannot find the answer, try [Troubleshooting](../support/troubleshooting.md). When asking for support, never include passwords, session tokens, API keys, relay credentials, private keys or private identity evidence.
